OverApp Command Center

A local-first project management and IDE-like application that provides real-time system monitoring, project visualization, prompt routing, cost tracking, and educational layers — all in one dashboard.

Daemon Architecture

Node.js/Express server running on 127.0.0.1:3011. All API calls are local-only — no external traffic leaves your machine.

SSE Streaming

Server-Sent Events push telemetry, logs, and updates to the frontend in real time.

Educational Layers

Five context layers (Foundation → Full Context) teach you how agent context depth works. Click any layer for details.

Prompt Router

Classifies tasks into Simple/Standard/Complex routes and selects the optimal model — model-agnostic and cost-aware.

Security Guardrails

Destructive commands (push --force, reset --hard, rm -rf) are blocked. All bindings are localhost only.

How It Works

1
User Prompt

You type a task or command in the agent loop.

2
Prompt Router

Task is classified (Simple/Standard/Complex) and routed to the optimal model.

3
ReAct Loop

Agent thinks → acts → observes → repeats until the task is resolved.

4
Cost Tracking

Every request is logged and tracked against your daily/weekly budget.

5
Handoff

When done, generate a handoff document to pass context to the next session or team member.

EDUCATIONAL LAYERHow Prompt Routing Works

Prompt routing classifies your task and selects the optimal model. This is agnostic — the same routing logic works whether you use Ollama, OpenAI, or any other provider. The system adapts to whatever models are available.

Simple$0.001/request
Fast, cheap models for: review, check, validate, test
Standard$0.005/request
Balanced models for: write, edit, implement, fix, refactor
Complex$0.01/request
Heavy models for: plan, architect, design, analyze, strategy

Educational Layer: Cost-Agnostic Design

This system is designed to be model-agnostic. The routing logic, cost tracking, and optimization strategies work regardless of the underlying LLM provider. When you switch models or providers, the same logic applies — only the cost parameters change.
