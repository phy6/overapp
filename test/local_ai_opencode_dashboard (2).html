OpenCode Agent Loop Architecture

OpenCode operates using an autonomous execution loop over local REST endpoints. Rather than single-turn prompt completions, OpenCode continuously queries local LLMs via tool bindings (`bash`, `read`, `write`, `edit`), parsing structured JSON responses to perform iterative code refactoring.

Ollama VRAM Management & Quantization

Ollama loads model weights directly into GPU VRAM using GGUF quantization formats (`Q4_K_M`, `Q8_0`). Quantization compresses 16-bit floating-point weights to 4-bit integers, enabling 14B and 32B models to fit seamlessly within standard consumer GPUs (8GB–24GB VRAM).
