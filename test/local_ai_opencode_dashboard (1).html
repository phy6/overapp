Local AI Telemetry & Engineering Guide

Understanding session responsiveness, KV cache, and agent execution

Why does local generation feel less responsive sometimes?

Unlike cloud APIs (like OpenAI or Anthropic) which stream tokens across ultra-high bandwidth GPU clusters, local generation performance depends heavily on your GPU VRAM bandwidth and context length. Large prompt payloads (e.g., 20,000+ tokens) require significant initial processing time (Prompt Processing phase) before token generation starts.

KV Cache & RAM Impact

The Key-Value (KV) Cache stores attention states for previous tokens so the LLM doesn't recompute the entire prompt on every turn. A 32k context window on a 14B model can consume over 2.5 GB of VRAM just for the KV cache!

OpenCode Optimization Tips

  • Use Q4_K_M or Q5_K_M quantization for optimum speed/quality balance.
  • Keep active workspace context clean by removing unused library files.
  • Reuse session cache by avoiding resetting the conversation needlessly.
  • Enable GPU layer offloading with num_gpu: 99 in Ollama.
